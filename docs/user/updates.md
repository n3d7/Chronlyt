# Updates and releases

Chronlyt releases are published through [GitHub Releases](https://github.com/n3d7/Chronlyt/releases).

Chronlyt is currently pre-stable (`0.x`) and moving toward a plugin-based platform. Release notes are the authoritative description of what a particular build contains. Read them before updating, especially while the plugin model and compatibility expectations are still changing.

Release assets may include Windows and Linux packages, checksums, signatures, and update metadata. Availability differs by release; use the verification and installation instructions provided with the release you download.

The [changelog](../../CHANGELOG.md) retains earlier entries as a historical record. Older entries can describe the previous fixed-feature application and should not be read as the current product definition.
